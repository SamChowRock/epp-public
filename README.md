# 第 1 章 Unix Shell：从第一条命令到独立写脚本

主线用两份五行合计的日志学习语法与工具，完成脚本见 [mainline](mainline/README.md)。

本目录的 check.sh 对应支线 1E.4 完成时的文件。可以先从空文件夹跟写，到比较脚本行为时再打开它。

在编辑器中创建“今日 请求.log”，填入下面三行并保存：

```text
200 GET /captures
404 GET /missing
200 GET /captures/404
```

在同一目录运行 `bash check.sh "今日 请求.log"`，应只看到中间一行。另存一份只有状态码 200 的日志，用新文件名再查，脚本会显示“已经查完，没有 404”。传入一个不存在的文件名时会显示诊断，随后立即运行 `printf '%s\n' "$?"` 可看到非零状态。第 2 章另从空目录建立 HTTP 服务。

## 支线 1E　按练习位置核对值班交接脚本

- 1E.3～1E.4 在本目录运行 `bash choose.sh 404 "今日 请求.log"`，换成 4.4 会得到输入诊断。单独的 check.sh 为完成的 404 检查，把无匹配当作已查完。
- 1E.4 在此目录运行 `bash publish.sh "今日 请求.log"`，打开“最近检查.txt”读回结果。换成不存在的日志名后，原报告仍可读，脚本会指出这次留下的过程文件。
- 1E.5 在本目录按支线创建周一和周二的样本，再运行 `bash check-batch.sh "周一 请求.log" "周二 请求.log"`。要从每行一个路径的名单读入，运行 `bash check-batch.sh --list < 交接名单.txt`。
- 1E.6 在编辑器打开“窗口实验”目录，依支线创建上午与下午两份样本，在此目录启动两个终端。`read-log.sh` 显示当前收到的选择；`. ./afternoon.sh` 把切换函数载入这个终端。
- 1E.7 在“等待实验”目录用 `bash probe.sh 3` 观察正常结束，再依正文从启动它的窗口比较前台中断与后台等待。

1E.8 的静态页面和交接脚本由你自行建立，用两份已知标题与上次报告检查新一轮结果。
