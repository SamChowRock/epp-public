# 1D 交出演示包

在 VS Code 打开本目录，双击制作台中的 index.html 可在浏览器核对蓝色标题和东门说明。新建“交出”和一个空的“接收”目录，在本目录运行 `bash pack-demo.sh "制作台" "交出"`。脚本在标准输出给出本轮新包的路径。用 `tar -tzf` 核对三个成员，用 `tar -xzf 包路径 -C 接收` 解开并从接收目录再次打开页面、点击说明。执行时把“包路径”换为本轮实际输出。

在自己的练习副本把 notice.txt 改名为 notice.hold，再运行，缺件这轮应返回非零且不在标准输出给出新包。用之前保存的路径重新列出旧包，之后将练习文件改回原名。
