# 交接包的只读复核

按支线 1A 在本机练习目录完成制备、解包，再打开终端进入本说明所在目录。输入 `bash check-install.sh` 和一个空格，从 Finder 拖入**解开后的白班包目录**，再输入空格和期望的 `B`。回滚后用相同目录与 `A` 复核。也可以输入加引号的路径。

脚本核对两个入口保存的相对目标、两条路线读出的文字、两版原文和版二点文件的完整内容，包括末尾换行。它以自己的运行身份读取，普通用户若要验证自身能否读取，可用该账号独立运行。脚本只读，成功返回 0，材料有误或缺失返回 1，调用格式错误返回 2。值守记录和返工包的交付说明由接手者按本次交接的实际文字独立核对。
